## 1. 一句话理解

RANSAC（Random Sample Consensus，随机采样一致性）是一类**在大量离群点存在时，仍能估计模型参数**的鲁棒算法。它不试图让所有数据都拟合模型，而是反复从数据中随机抽取最小样本建模，找出支持该模型的最大一致集。

典型用途：直线/平面拟合、相机位姿估计、基础矩阵与单应矩阵估计、点云分割、SLAM 前端误匹配剔除。

## 2. 为什么需要 RANSAC

最小二乘法会最小化所有点的总体残差：
[[最小二乘法]]

\[ $\min_{\theta}\sum_{i=1}^{N} r_i(\theta)^2$ \]

其中 $\theta$ 为模型参数，$r_i$ 为第 $i$ 个点的残差。

当错误匹配、深度噪声或动态物体产生离群点（outlier）时，平方项会放大它们的影响，导致模型被“拉偏”。RANSAC 的思想是：**只用彼此一致的内点（inlier）估计模型**。

|术语|含义|
|---|---|
|内点|与当前模型误差小于阈值的数据点|
|离群点|误差大于阈值的数据点|
|最小样本集（MSS）|恰好足以确定一个模型的最少点数|
|一致集（consensus set）|被某模型判定为内点的全部数据|

例如：二维直线至少需要 $s=2$ 个点；三维平面至少需要 $s=3$ 个不共线点；单应矩阵通常至少需要 $s=4$ 对点；基础矩阵常见最小求解器为 7 点或 8 点法。

## 3. 核心流程

1. 从全部数据中随机抽取 $s$ 个样本。
2. 用这 $s$ 个样本估计一个候选模型 $\theta$。
3. 计算每个数据点到模型的残差 $r_i$。
4. 若 $r_i < \tau$，将该点判为内点；$\tau$ 为内点阈值。
5. 记录内点数最多（或评分最高）的模型。
6. 重复以上过程若干次。
7. 用最终最佳模型的全部内点重新优化参数。

## 迭代次数如何计算

设：

- $w$：内点比例；
- $s$：一次建模需要的最小样本数；
- $p$：至少有一次抽样全部为内点的成功概率；
- $N$：需要的迭代次数。

一次随机抽到全内点最小样本集的概率为：

$\[ w^s \]$

连续 $N$ 次都失败的概率为：

$\[ (1-w^s)^N \]$

希望成功概率至少达到 $p$，则：

$\[ 1-(1-w^s)^N \ge p \]$

解得：

$\[ N \ge \frac{\ln(1-p)}{\ln(1-w^s)} \]$

### 例子

若内点比例估计为 $w=0.5$，用两点拟合直线（$s=2$），希望成功率 $p=0.99$：

$\[ N \ge \frac{\ln(1-0.99)}{\ln(1-0.5^2)} \approx 16.0 \]$

因此至少迭代约 $17$ 次。注意：若 $w$ 下降或 $s$ 增大，所需次数会迅速增加。


## 5. 常见模型与残差

### 5.1 二维直线拟合

直线一般式：

\[ ax+by+c=0 \]

点 $(x_i,y_i)$ 到直线的垂直距离为：

$\[ d_i=\frac{|ax_i+by_i+c|}{\sqrt{a^2+b^2}} \]$

若 $d_i<\tau$，该点为内点。

### 5.2 三维平面拟合

平面方程：

\[ ax+by+cz+d=0 \]

点 $mathbf{p}_i=(x_i,y_i,z_i)^T$ 到平面的距离：

$\[ d_i=\frac{|ax_i+by_i+cz_i+d|}{\sqrt{a^2+b^2+c^2}} \]$

这常用于深度相机点云中的桌面、墙面、地面提取。

### 5.3 特征匹配中的单应矩阵

对于平面场景或纯旋转相机，匹配点满足：

$\[ \mathbf{x}' \sim \mathbf{H}\mathbf{x} \]$

其中 $\mathbf{H}$ 是 $3\times3$ 单应矩阵，$\sim$ 表示齐次坐标下相差非零尺度。RANSAC 用重投影误差判断内点：

$\[ e_i=\left\|\mathbf{x}'_i-\pi(\mathbf{H}\mathbf{x}_i)\right\|_2 \]$

## 6. 参数怎么调

| 参数                   | 作用       | 调参建议                                              |
| -------------------- | -------- | ------------------------------------------------- |
| `threshold` / $\tau$ | 内点判定阈值   | 与测量噪声同量级；特征像素误差常从 1–3 px 尝试，点云平面常从 0.01–0.03 m 尝试 |
| `maxIters`           | 最大迭代次数   | 离群点越多，设置越大；也可按上式估算                                |
| `confidence` / $p$   | 目标成功概率   | 常用 0.99 或 0.999                                   |
| `min_inliers`        | 最低可接受内点数 | 防止偶然形成的假模型被接受                                     |
| 模型最小样本数 $s$          | 由模型决定    | 应使用数值稳定的最小求解器                                     |
|                      |          |                                                   |


阈值太小会把真实内点误判为离群点；阈值太大会把错误点混入内点集。实际应结合传感器噪声、分辨率和场景距离调节。

## 7. RANSAC 在视觉与 SLAM 中的作用

### 7.1 ORB/SIFT 特征匹配后剔除误匹配
[[SIFT]]

描述子匹配只能得到“外观相似”的候选对应，仍会有大量错误匹配。可用 RANSAC 估计：

- 单应矩阵 `findHomography`：平面目标、图像拼接；
- 基础矩阵 `findFundamentalMat`：双目/单目两视图几何；
- 本质矩阵 `findEssentialMat`：已知相机内参时的相对位姿；
- PnP 位姿 `solvePnPRansac`：2D–3D 对应下的相机位姿。

只有几何误差满足阈值的匹配，才会进入后续位姿估计或建图。

### 7.2 深度相机点云分割

对 RGB-D 相机生成的点云，可用平面 RANSAC：
[[RGB-D视觉里程]]
1. 找到最大平面，例如地面或桌面；
2. 删除该平面的内点；
3. 对剩余点进行聚类和目标检测。

注意：反光屏幕、玻璃、边缘飞点和深度空洞会产生较多离群点，应先做深度范围裁剪和统计滤波。


## 优点、局限与改进

|项目|说明|
|---|---|
|优点|对高比例离群点鲁棒；概念简单；适用于多种几何模型|
|局限|随机性导致每次结果可能略不同；内点率很低时迭代次数很大；阈值需要经验设置|
|常见改进|MSAC、MLESAC、PROSAC、LO-RANSAC、USAC、MAGSAC++|

- **PROSAC**：优先从匹配质量更高的数据中采样，适合特征匹配。
- **LO-RANSAC**：找到较好模型后进行局部优化，提高精度。
- **MAGSAC++**：弱化对固定阈值的依赖，现代视觉库中常见。

## 10. 易错点

1. **把 RANSAC 当成最终优化器**：它主要负责找内点；最后应对内点做最小二乘、LM 或 BA 优化。
2. **阈值单位混乱**：图像问题多为像素，点云问题多为米；不要直接照搬数值。
3. **最小样本退化**：如直线的两点重合、平面的三点共线、PnP 点分布过于集中，都会使模型不稳定。
4. **内点数多不一定正确**：大平面或重复纹理可能生成错误但“支持者很多”的模型，应结合场景先验和误差分布判断。
5. **没有重新拟合**：只用最小样本集的模型噪声大，必须使用全部内点重新估计。

## 11. 速记总结

> RANSAC = 随机抽取最小样本建模 + 用误差阈值找内点 + 保留最大一致集 + 用全部内点重新优化。

在视觉里，它最常用于把“描述子相似”筛成“几何上也成立”的匹配；在点云里，它最常用于从含噪数据中找到主平面。
