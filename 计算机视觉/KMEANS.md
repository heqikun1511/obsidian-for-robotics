
# K-means 算法详细笔记

> K-means 是经典无监督聚类算法：指定簇数 $K$ 后，把样本划分为 $K$ 组，使簇内样本尽量接近各自中心。

## 1. 问题定义

给定 $N$ 个 $d$ 维样本：

$\[ \mathcal{X}=\{\mathbf{x}_1,\mathbf{x}_2,\ldots,\mathbf{x}_N\}, \qquad \mathbf{x}_i\in\mathbb{R}^d \]$

希望得到 $K$ 个簇：

$\[ \mathcal{C}=\{C_1,C_2,\ldots,C_K\} \]$

每个簇由中心 $\boldsymbol{\mu}_k$ 表示。令 $r_{ik}$ 表示样本 $i$ 是否属于簇 $k$：

$\[ r_{ik}= \begin{cases} 1, & \mathbf{x}_i\text{ 属于 }C_k\\ 0, & \text{否则} \end{cases} \qquad \sum_{k=1}^{K}r_{ik}=1 \]$


## 2. 目标函数

K-means 最小化样本到所属簇中心的平方欧氏距离和：

$\[ J= \sum_{i=1}^{N}\sum_{k=1}^{K} r_{ik} \left\|\mathbf{x}_i-\boldsymbol{\mu}_k\right\|_2^2 \]$

它也叫簇内平方和、SSE、WCSS 或 inertia。它追求的是簇内紧凑，而不是直接最大化簇间距离。

## 3. 两步交替迭代

### 3.1 分配步骤

固定中心，让每个样本选择最近中心：

$\[ z_i= \arg\min_{k\in\{1,\ldots,K\}} \left\|\mathbf{x}_i-\boldsymbol{\mu}_k\right\|_2^2 \]$

其中 $z_i$ 是样本 $\mathbf{x}_i$ 的簇标签。

### 3.2 更新步骤

固定标签，将每个簇中心更新为簇内样本均值：

$\[ \boldsymbol{\mu}_k= \frac{1}{|C_k|} \sum_{\mathbf{x}_i\in C_k}\mathbf{x}_i \]$

这里的均值不是经验规则。对单簇目标：

$\[ J_k(\boldsymbol{\mu}_k)= \sum_{\mathbf{x}_i\in C_k} \left\|\mathbf{x}_i-\boldsymbol{\mu}_k\right\|_2^2 \]$

求导并令其为零：

$\[ \frac{\partial J_k}{\partial\boldsymbol{\mu}_k} =2\sum_{\mathbf{x}_i\in C_k} (\boldsymbol{\mu}_k-\mathbf{x}_i)=0 \]$

所以：

$\[ \boldsymbol{\mu}_k= \frac{1}{|C_k|} \sum_{\mathbf{x}_i\in C_k}\mathbf{x}_i \]$

这就是 K-means 名字中 means 的由来。

## 4. 算法流程

1. 选择簇数 $K$；
2. 初始化 $K$ 个中心；
3. 分配：每个样本归入最近中心；
4. 更新：每个中心移动到本簇均值；
5. 重复步骤 3、4，直到收敛。

常见停止条件为中心移动很小：

$\[ \max_k \left\| \boldsymbol{\mu}_k^{(t)} -\boldsymbol{\mu}_k^{(t-1)} \right\|_2<\epsilon$ \]

也可在标签不再变化或达到最大迭代轮数时停止。

## 5. 为什么会收敛但不保证最好？

每次分配都不会增加 $J$，每次均值更新也不会增加 $J$；又因为：

$\[ J\ge 0 \]$

所以算法最终会收敛到稳定解。但目标函数非凸，不同初始化可能落到不同局部最优。

实践中应多次重启：

$\[ J^\ast=\min_{m\in\{1,\ldots,M\}}J^{(m)} \]$

保留 $M$ 次结果中目标函数最小的那次。


## 6. K-means++ 初始化

随机初始化可能让多个中心聚在同一片区域。K-means++ 的做法：

1. 随机选择第一个中心；
2. 计算每个样本到最近已选中心的距离 $D(\mathbf{x})$；
3. 以下列概率选择下一个中心：

$\[ P(\mathbf{x}_i)= \frac{D(\mathbf{x}_i)^2} {\sum_{j=1}^{N}D(\mathbf{x}_j)^2} \]$

4. 直到选出 $K$ 个中心；
5. 执行标准 K-means。

它让初始中心彼此更分散，通常明显更稳定。

## 7. 如何选簇数 $K$

### 肘部法

绘制 $J(K)$ 与 $K$ 的曲线。增加 $K$ 总会让 $J$ 降低；寻找“继续增加簇数但下降变慢”的弯折点。

### 轮廓系数

对样本 $i$：

- $a(i)$：到本簇其他样本的平均距离；
- $b(i)$：到最近其他簇样本的平均距离。

$\[ s(i)= \frac{b(i)-a(i)} {\max(a(i),b(i))} \]$

| 分数   | 含义         |
| ---- | ---------- |
| 接近 1 | 簇内紧凑，簇间分离好 |
| 接近 0 | 样本位于边界附近   |
| 小于 0 | 可能被分错簇     |

## 8. 特征缩放：重要前提

K-means 依赖欧氏距离。若一个特征量纲远大于其他特征，它会主导聚类。例如用位置毫米数和速度米每秒共同聚类时，位置会掩盖速度。

常用标准化：

$\[ x_{ij}^{\prime}= \frac{x_{ij}-\mu_j}{\sigma_j} \]$

或 Min-Max 缩放：

$\[ x_{ij}^{\prime}= \frac{x_{ij}-x_j^{\min}} {x_j^{\max}-x_j^{\min}} \]$

标准化的均值与标准差必须只由训练数据计算，再应用到后续数据。

## 9. 时间复杂度

每轮迭代要比较 $N$ 个样本与 $K$ 个中心，每次为 $d$ 维距离计算。迭代 $T$ 轮时：

\[ O(NKdT) \]

数据集很大时可用 MiniBatch K-means：每轮只抽取一个小批量更新中心，速度快但结果为近似。

## 10. 它适合与不适合什么数据？

| 情况          | 原因               | 更合适的选择          |
| ----------- | ---------------- | --------------- |
| 近似球状、大小相近的簇 | 符合欧氏距离与均值中心假设    | K-means         |
| 弯月形、环状簇     | 单个均值无法描述形状       | 谱聚类、DBSCAN      |
| 密度、大小差异很大   | K-means 偏好相近大小的簇 | GMM、DBSCAN      |
| 异常值很多       | 均值会被极端点拉动        | K-medoids、鲁棒预处理 |
| 空簇          | 某中心没有分到样本        | 把中心重置到最远样本附近    |
|             |                  |                 |


## 11. K-means、GMM 与 K-medoids

| 算法        | 归属方式  | 簇形状   | 簇代表    | 抗异常值 |
| --------- | ----- | ----- | ------ | ---- |
| K-means   | 硬分配   | 近似球状  | 均值     | 较弱   |
| GMM       | 概率软分配 | 椭圆状   | 均值与协方差 | 中等   |
| K-medoids | 硬分配   | 取决于距离 | 真实样本点  | 较强   |
