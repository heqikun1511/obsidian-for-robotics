日常启动相机：

```

source /opt/ros/jazzy/setup.bash
source install/setup.bash

ros2 launch orbbec_camera ob_camera.launch.py \
  camera_name:=camera \
  color_width:=640 color_height:=480 color_fps:=30 color_format:=MJPG \
  depth_width:=640 depth_height:=400 depth_fps:=30 depth_format:=Y12 \
  ir_width:=640 ir_height:=400 ir_fps:=30 ir_format:=Y8 \
  enable_point_cloud:=true
```


如果启动时仍提示无法设置流，用最小配置排查：

```
ros2 launch orbbec_camera ob_camera.launch.py \
  camera_name:=camera \
  depth_format:=Y12 \
  enable_ir:=false \
  enable_point_cloud:=true
```

验证彩色、深度和点云：

```
source /opt/ros/jazzy/setup.bash
source /home/amoy/F407_active/joho_snake_robot/install/setup.bash

ros2 topic hz /camera/color/image_raw
ros2 topic hz /camera/depth/image_raw
ros2 topic echo /camera/depth/points --once
```

话题齐全。RTAB-Map 先使用这组数据：

```
RGB：       /camera/color/image_raw
RGB 内参：  /camera/color/camera_info
深度：      /camera/depth/image_raw
深度内参：  /camera/depth/camera_info
```

先安装 RTAB-Map：

```
sudo apt install ros-jazzy-rtabmap-ros
```

保持相机节点运行后，另开终端执行 RGB-D 视觉建图：

```
cd /home/amoy/F407_active/joho_snake_robot
source /opt/ros/jazzy/setup.bash
source install/setup.bash

ros2 launch rtabmap_launch rtabmap.launch.py \
  rtabmap_args:="--delete_db_on_start --Reg/Force3DoF true --Grid/FromDepth true" \
  rgb_topic:=/camera/color/image_raw \
  depth_topic:=/camera/depth/image_raw \
  camera_info_topic:=/camera/color/camera_info \
  depth_camera_info_topic:=/camera/depth/camera_info \
  frame_id:=camera_link \
  odom_frame_id:=odom \
  approx_sync:=true \
  rgbd_sync:=true \
  visual_odometry:=true \
  publish_tf_odom:=true \
  wait_imu_to_init:=false \
  qos:=2 \
  rtabmap_viz:=true \
  rviz:=false
```

这是第一阶段的“纯相机建图与定位”。缓慢移动蛇头和机身，让相机观察到墙面、桌椅、门框等有纹理特征；不要只对着纯地面或白墙，否则视觉里程计会丢失。

验证它是否正常发布位姿和地图：

```
ros2 topic list | grep -E '(/odom|/map|rtabmap)'
ros2 run tf2_ros tf2_echo odom camera_link
```

看到持续变化的 `odom → camera_link` 变换，以及 `/map` 后，纯相机定位链路就建立了。

此阶段先不要启动 `use_nav2:=true`。下一步要把相机 `camera_link` 相对机器人 `base_link` 的固定安装位姿加入 TF，然后让 Nav2 使用：

彩色与深度时间差约 14–18 ms，当前 `approx_sync:=true` 已能处理，不是主因。
