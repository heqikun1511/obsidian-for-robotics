

深度相机是一种不仅能拍到颜色，还能测出画面中每个像素距离相机多远的传感器。

普通 RGB 相机输出的是二维图像：

\[ I(u,v)=[R,G,B] \]

深度相机还会输出一张深度图：

\[ D(u,v)=Z \]

其中 \(Z\) 通常表示该像素到相机光心沿视线方向的距离，单位常为米或毫米。把 RGB 图与深度图结合，就能恢复场景的三维点云：

$\[ X=\frac{(u-c_x)Z}{f_x},\quad Y=\frac{(v-c_y)Z}{f_y},\quad Z=D(u,v) \]$

这里 \$(f_x,f_y,c_x,c_y$\) 是相机内参。

常见实现方式：

| 类型     | 原理                  | 优点             | 局限                    |
| ------ | ------------------- | -------------- | --------------------- |
| 双目深度相机 | 两个相机看同一物体，利用视差计算距离  | 室外适应性较好，可无主动发光 | 纹理少、暗处或反光表面效果差        |
| 结构光    | 投射特定红外散斑图案，观察图案变形   | 近距离精度高         | 阳光中的红外会干扰，量程通常较短      |
| ToF    | 发射调制红外光，测量返回相位/飞行时间 | 深度图稠密，近距离稳定    | 多径反射、强光、金属/玻璃表面可能影响结果 |
| 主动双目   | 双目 + 红外投射纹理         | 无纹理环境更稳定       | 仍会受阳光和反光影响            |

在机器人中，它最常用于：

- 近距离避障：识别前方人、桌腿、货物；
- 点云建图与三维重建；
- 识别托盘、箱体、物体尺寸和抓取位姿；
- 视觉 SLAM：结合 RGB、深度与 IMU 定位；
- 语义分割后的三维定位，例如把“人”或“托盘”的像素转换到机器人坐标系。

对你的树莓派机器人或无人叉车项目，它可以补足 2D 雷达“只看一个平面”的局限：雷达负责稳定的平面定位与远距离障碍，深度相机负责近距离三维物体、悬空障碍物、货物和托盘细节。

但深度相机不是“低成本 3D 激光雷达”的完全替代品：有效距离通常更近，FOV 较窄，对室外阳光、玻璃、黑色/反光材料和灰尘更敏感。
