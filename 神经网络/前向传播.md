## 一、核心公式（图中下方蓝色部分）

图里给出了每一层的计算三步曲：

text

Z = XW + b          （线性加权 + 加偏置）
A = f(Z)            （激活函数，引入非线性）

- **X**：输入（上一层的输出）
    
- **W**：权重矩阵（可学习参数）
    
- **b**：偏置向量（可学习参数）
    
- **f**：激活函数（如 ReLU、Sigmoid、Tanh）
    
- **A**：本层输出，传给下一层
    

这正好对应标题那句：

> **线性加权 → 加偏置 → 激活函数**


## 二、逐层拆解（以图中的猫识别为例）

### 输入层（3 个特征）

- 输入向量 `X = [x₁, x₂, x₃]`，形状 `(1, 3)`
    
- 三个特征分别是：
    
    - `x₁`：**边缘**
        
    - `x₂`：**颜色**
        
    - `x₃`：**纹理**
        

> 这是最原始、最底层的像素级信息。

### 隐藏层 1（4 个神经元）—— 学到局部模式

- 公式：`Z₁ = XW₁ + b₁`，`A₁ = f(Z₁)`
    
- 形状变化：输入 `(1, 3)` → 权重 `W₁` 形状 `(3, 4)` → 输出 `A₁` 形状 `(1, 4)`
    
- 4 个神经元学到：
    
    - `h₁₁`：圆形 / 角点
        
    - `h₁₂`：深色区域
        
    - `h₁₃`：水平边缘
        
    - `h₁₄`：高频纹理
        

> 这一层把"像素"组合成了**局部特征**（类似边缘检测器）。

## 单神经元形式（通项公式）

图上第一个公式：

$ai(l)=σ(∑j=1nwij(l)aj(l−1)+bi(l))ai(l)​=σ(j=1∑n​wij(l)​aj(l−1)​+bi(l)​)$

### 符号逐个解释

|符号|含义|
|---|---|
|ai(l)ai(l)​|第 ll 层、第 ii 个神经元的**输出（激活值）**|
|σσ|激活函数（Sigmoid / ReLU / Tanh 等）|
|∑j=1n∑j=1n​|对上一层所有神经元求和，nn 是上一层神经元数量|
|wij(l)wij(l)​|权重：从第 l−1l−1 层第 jj 个 → 第 ll 层第 ii 个|
|aj(l−1)aj(l−1)​|上一层的第 jj 个神经元输出|
|bi(l)bi(l)​|第 ll 层第 ii 个神经元的偏置|

### 直观理解

> 每个神经元的输出 = **加权求和** 上一层所有输出 → **加偏置** → **过激活函数**

这正是上一张图"前向传播"里那条链：**线性加权 → 加偏置 → 激活函数**。

## 为什么需要矩阵化？

如果按单个神经元逐个计算：

text

for i in 1..m:          # 本层 m 个神经元
    for j in 1..n:      # 上一层 n 个神经元
        sum += w[i][j] * a[j]
    out[i] = sigma(sum + b[i])

问题：

- **循环嵌套**，计算慢
    
- **Python 层循环**极慢（如果是 numpy 逐个算）
    
- **无法利用 GPU / SIMD 并行**
## 为什么"天然适合 GPU"？

图底那句话是精髓：

> 神经网络计算天然适合 GPU——它就是一连串大型矩阵乘法。

### GPU 擅长什么？

|运算|GPU 表现|神经网络中对应|
|---|---|---|
|**大规模并行**|⭐⭐⭐⭐⭐|每个神经元、每个样本独立|
|**矩阵乘法**|⭐⭐⭐⭐⭐|每层的核心运算|
|**逐元素运算**|⭐⭐⭐⭐⭐|激活函数、加法|
|**分支/逻辑控制**|⭐⭐|神经网络很少用|

### 对比 CPU vs GPU

text

CPU：几十个核心，每个核心很强，适合串行/复杂逻辑
GPU：几千个核心，每个核心简单，适合大规模并行
矩阵乘法 (m,n) × (n,B) 中：
- 有 m×B 个输出元素
- 每个元素 = n 次乘加
- 所有元素可完全并行
→ 完美契合 GPU 架构
