
[[蛇形机器人]]

## 基本工作原理

每个总线舵机内部不只是“电机 + 电位器 + 简单控制板”，还多了：

- MCU/通信芯片
- 唯一 ID（地址）
- 位置、速度、电流、电压、温度等采样功能
- 闭环控制算法

控制器发送一个数据包，例如：

```
[帧头] [舵机ID] [指令] [参数长度] [参数] [校验]
```

假设给 ID 为 `3` 的舵机下发位置命令：

```
AA 55 03 01 02 84 03 XX
```

它的逻辑含义可能是：

```
帧头      → AA 55
目标地址  → 03号舵机
指令      → 设置目标位置
参数      → 目标位置，例如 900
校验      → 防止数据出错
```

总线上的每个舵机都会收到这串数据，但只有地址匹配的 `ID=3` 舵机会执行命令；其他舵机忽略。

## 一条线如何既发送又接收？

许多舵机采用 **半双工 UART**。

也就是同一根 `DATA` 线在不同时间承担不同角色：

1. 控制器发送命令；
2. 控制器停止驱动数据线、切换为接收；
3. 被点名的舵机回复状态；
4. 总线回到空闲状态，等待下一条命令。

例如：

```
控制器 → 总线：读取 ID=5 的当前位置
ID=5舵机 → 总线：当前位置=1420，温度=36°C
```

因为同一时刻只能有一个设备说话，所以控制器必须避免让多个舵机同时回复。

## 为什么要有 ID 地址？

因为所有舵机接在同一总线上，必须通过 ID 区分对象。

常见操作有：

- `ID=1`：左前关节
- `ID=2`：右前关节
- `ID=3`：摄像头云台
- `ID=4`：夹爪

同一个总线上，**ID 不能重复**。否则两个舵机会同时响应同一命令，造成动作混乱，读取反馈时还可能产生通信冲突。

通常第一次配置时，会把单个舵机接到总线，写入一个唯一 ID，再接入整机。
