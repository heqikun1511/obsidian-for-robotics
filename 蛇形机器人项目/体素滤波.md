**体素滤波**（Voxel Filter / Voxel Grid Filter）是点云处理中最常用的**降采样（downsampling）**方法。它把三维空间划分成规则的小立方体（体素），每个立方体只保留一个代表点，从而大幅减少点数，同时保持点云的整体形状。

---

## 一、名字拆解

| 词          | 含义                                             |
| ---------- | ---------------------------------------------- |
| **Voxel**  | Volume + Pixel，即"体素"，三维空间中的一个小立方体（相当于 3D 版的像素） |
| **Grid**   | 网格，把空间规则划分                                     |
| **Filter** | 滤波，这里指"筛选/降采样"                                 |

**Voxel Grid Filter = 体素网格滤波器**


## 二、核心思想（一句话）

> 把三维空间切成很多小立方体，每个立方体里的所有点，用一个点来代替（通常是重心）。

这样：

- 点数从几十万 → 几万
    
- 形状基本不变
    
- 后续算法速度提升数倍


## 三、算法步骤

假设体素大小为 `leaf_size = 0.03m`（3cm）：

### 步骤 1：确定包围盒

找出点云在 x、y、z 方向的最小值和最大值，形成一个**包围盒（bounding box）**。

text

点云范围：
  x: [0.0, 5.0]
  y: [-2.0, 2.0]
  z: [-0.5, 1.5]


### 步骤 2：划分体素网格

按 `leaf_size` 把包围盒切成小立方体：

text

x 方向: (5.0 - 0.0) / 0.03 ≈ 167 个格子
y 方向: (2.0 - (-2.0)) / 0.03 ≈ 133 个格子
z 方向: (1.5 - (-0.5)) / 0.03 ≈ 67 个格子
总共约 167 × 133 × 67 ≈ 149 万个体素

### 步骤 3：点分配到体素

每个点 `(x, y, z)` 计算它落在哪个体素：

cpp

int ix = floor((x - min_x) / leaf_size);
int iy = floor((y - min_y) / leaf_size);
int iz = floor((z - min_z) / leaf_size);
voxel_index = (ix, iy, iz);


### 步骤 4：每个体素取代表点

对每个非空体素，用以下方式之一生成代表点：

| 方法         | 说明              |
| ---------- | --------------- |
| **重心（质心）** | 默认，取所有点的平均值，最平滑 |
| 中心点        | 取体素几何中心         |
| 最近点        | 取离体素中心最近的点      |
| 第一个点       | 取最先遇到的点，最快      |

**PCL 默认用重心**。
