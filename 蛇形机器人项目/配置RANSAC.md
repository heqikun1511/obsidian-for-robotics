## 第二组：地面 RANSAC 配置

### 6. `bool ground_filter_enabled_{true};`

| 项目  | 说明             |
| --- | -------------- |
| 类型  | `bool`         |
| 默认值 | `true`（**开启**） |
| 含义  | 是否启用**地面分割**   |
| 用途  | 分离地面点和障碍物点     |

**为什么默认开？** 地面分割是障碍物检测的前提，几乎总是需要。默认开更合理。

对应参数：`ground_filter_enabled`（默认 true）

###  `double ground_distance_threshold_m_{0.035};`

| 项目  | 说明                         |
| --- | -------------------------- |
| 类型  | `double`                   |
| 默认值 | `0.035`（米）                 |
| 含义  | **点到地面平面的距离阈值**，3.5cm      |
| 用途  | RANSAC 拟合平面时，距离小于此值的点算地面内点 |
|     |                            |



### `int ground_min_points_{120};`

| 项目  | 说明                     |
| --- | ---------------------- |
| 类型  | `int`                  |
| 默认值 | `120`                  |
| 含义  | **拟合地面所需的最少点数**        |
| 用途  | 点数不足时不拟合地面，避免用少量噪声点乱拟合 |

**为什么需要？** RANSAC 是随机采样，点太少时拟合结果不稳定。

对应参数：`ground_min_points`（默认 120）

### `double ground_max_tilt_deg_{20.0};`

| 项目  | 说明                     |
| --- | ---------------------- |
| 类型  | `double`               |
| 默认值 | `20.0`（度）              |
| 含义  | **地面最大倾斜角**            |
| 用途  | 法向量与 z 轴夹角超过 20° 就不算地面 |
|     |                        |

**配合 `constrain_ground_normal_` 使用**：

text

地面法向量与 z 轴夹角：
  ≤ 20°  → 算地面（平地或缓坡）
  > 20°  → 不算地面（斜坡、墙面、障碍物）

对应参数：`ground_max_tilt_deg`（默认 20.0）
