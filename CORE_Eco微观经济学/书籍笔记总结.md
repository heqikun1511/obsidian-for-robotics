# 第2章 技术与激励

## 2.1 Kutesmart自动化定制服装

Kutesmart案例展示企业为何采用自动化和数字化技术：新技术提高定制生产效率、降低单位成本，并可能使企业在竞争中获得暂时的超额收益。

关键问题不是“新技术是否先进”，而是：在工资、设备、能源等价格给定时，它是否比现有方案更有利可图？

## 2.2 机会成本、经济租与激励

### 机会成本

选择某行动时放弃的“次优替代方案”的净收益：

$[$  
$\text{机会成本}=\text{最佳未选方案的价值}$  
$]$

机会成本不是所有被放弃方案之和，也不一定等于实际支付的货币成本。

### 经济租

采取某行动相对于次优选择多得到的收益：

$[$  
$\text{经济租}=\text{所选方案收益}-\text{次优方案收益}$  
$]$

若经济租为正，选择当前行动更有吸引力；经济租越大，激励通常越强。

### 相对价格与激励

决策取决于价格之间的比例，而不只是某个价格的绝对值。例如工资相对机器和能源越贵，节省劳动的技术越有吸引力。

## 2.3 比较优势、专业化与市场

### 绝对优势与比较优势

- **绝对优势**：用较少投入生产同样数量的产品；
    
- **比较优势**：生产某产品的机会成本更低。
    

即使某人生产所有商品都更高效，双方仍可能通过按比较优势专业化并交换而获益。

判断比较优势的步骤：

1. 算出每个生产者生产两种商品的机会成本；
    
2. 比较谁生产某商品的机会成本更低；
    
3. 由其专业化生产该商品；
    
4. 检查交换比率是否位于双方机会成本之间。
    

专业化收益需要协调与交换，市场扩大和企业组织使更细的分工成为可能。

## 2.4 企业、技术与生产

企业可以在多种可行技术间选择。每项技术用不同组合的投入生产相同产出，例如：

- 劳动密集型：多用工、少用机器或能源；
    
- 资本/能源密集型：少用工、多用机器或能源。
    

如果一种技术在所有投入上都不少于另一种、且至少一种投入更多，它就是**被支配技术**，理性的成本最小化企业不会选它。

## 2.5 技术与成本模型

设工资为(w)，煤或能源价格为(p)，某技术使用劳动(L)和能源(R)，总成本为：

$[$  
$C=wL+pR$  
$]$

对于给定成本(C)，等成本线为：

$[$  
$R=\frac{C}{p}-\frac{w}{p}L$  
$]$

斜率是：

$[$  
$-\frac{w}{p}$  
$]$

其绝对值反映劳动相对于能源的价格。企业会在可行技术中选择位于最低等成本线上的方案。

## 2.6 创新与利润

新技术若使单位成本下降，创新企业在竞争者尚未采用前可获得**创新租**：

$[$  
$\text{创新租}=\text{旧技术成本}-\text{新技术成本}-\text{采用或研发成本}$  
$]$

竞争会促使其他企业模仿：

1. 先采用者获得超额利润；
    
2. 竞争者采用新技术；
    
3. 市场价格可能下降；
    
4. 创新租逐渐消失；
    
5. 企业继续寻找下一项创新。
    

因此，暂时性经济租可以成为持续创新的动力。


## 殖民地、奴隶制与英国工业革命

英国工业化不仅来自国内技术和价格激励，也依赖扩张的市场、殖民贸易、廉价原料、食物供给和奴隶劳动。它们可能：

- 扩大制成品销售市场；
    
- 提供棉花等投入；
    
- 支撑城市化和专业化；
    
- 将部分社会与人道成本转移给殖民地和被奴役者。
    

分析经济增长时，不能把国内产出增长自动等同于所有参与者福利提高。


# 尽力做到最好：稀缺、福祉与工作时间

## 3.1 如果时薪翻倍，你会减少工作吗？

本章从“工资提高后工作多久”切入。工资上涨并不能单独决定工作时长，因为人可以把生产率提高带来的收益用于：

- 增加消费；
    
- 增加自由时间；
    
- 同时增加二者。
    

历史数据表明，长期实际工资上升通常伴随消费提高和工作时间下降，但不同国家的组合不同。例如高收入国家之间也可能有相似收入、不同工时，或相似闲暇、不同收入的情况。

### 相关不等于因果

收入高与工作时间短同时出现，不足以证明“收入提高必然导致工时下降”。生产率、制度、文化、劳动法、税收和谈判力量都可能同时影响它们。

### 一个比例计算易错点

原工资£20/小时、每周40小时，周收入£800。工资提高25%后为£25/小时。若保持收入不变：

$[$  
$h=\frac{800}{25}=32\text{小时}$  
$]$

工作时间从40降到32，即下降20%，不是25%。原因是“价格上涨25%”与“数量下降25%”不是互为逆运算。


## 选择与稀缺问题

### 稀缺

如果某物有价值，而且获得更多它需要放弃其他有价值的东西，它就是稀缺的。

Karim同时看重：

- **消费**：购买消费品和服务的支出；
    
- **自由时间**：不工作的时间。
    

两者不能无限增加，所以他面对稀缺与选择。

### 工资、工时与收入

设：

- (w)：时薪；
    
- (h)：每日工作时数；
    
- (y)：每日收入。
则：

[  
y=wh  
]

在(w=30)欧元/小时的例子中：

[  
y=30h  
]

收入—工时线是一条过原点的直线，斜率为工资：

$[$  
$\frac{\Delta y}{\Delta h}=w=30$  
$]$

含义：每增加一小时工作，收入增加30欧元。

但“收入最大化”不等于“福祉最大化”。若Karim也重视自由时间，他未必选择允许的最长工作时间。
