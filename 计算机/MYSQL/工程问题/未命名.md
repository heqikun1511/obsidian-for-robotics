[[MYSQL 工程设计问题]]
### `CONSTRAINT uk_substation_name UNIQUE (substation_name)`

这是一个**唯一约束**，作用是保证 `substation_name`（变电站名称）这一列的值在整张表中**不重复**。

- **`CONSTRAINT uk_substation_name`**：给这个约束起名叫 `uk_substation_name`（`uk` 通常是 unique key 的缩写）。命名后便于后续通过名字删除或修改该约束（如 `DROP INDEX uk_substation_name`）。
    
- **`UNIQUE (substation_name)`**：声明 `substation_name` 列上的值必须唯一。插入或更新时，如果出现重复的变电站名称，数据库会直接报错拒绝。
    
- **实现方式**：在 InnoDB 中，唯一约束底层通过**唯一索引**实现，因此它同时具备索引加速查询的作用。
    
- **注意**：唯一约束允许多个 `NULL` 值（因为 SQL 中 `NULL != NULL`），除非该列同时被定义为 `NOT NULL`。
    

### ⚙️ `ENGINE=InnoDB`

指定这张表使用的**存储引擎**为 `InnoDB`。

- InnoDB 是 MySQL 默认的存储引擎，支持**事务**（ACID）、**行级锁**、**外键**和**崩溃恢复**。
    
- 对于有唯一约束、主键、外键关系的业务表（如变电站信息表），InnoDB 是标准选择。
