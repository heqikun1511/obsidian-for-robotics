


## 本质是一个服务器

### Nginx 的主要功能

**1. 静态 Web 服务器**  
这是它最基础的功能。你可以把 HTML、CSS、图片、视频等文件放在服务器上，Nginx 能非常快地把它返回给浏览器。相比传统的 Apache 服务器，Nginx 在处理大量并发连接时占用的内存更少，速度更快。

**2. 反向代理**  
这是 Nginx 最核心的用途之一。当用户访问一个网站时，请求先到达 Nginx，Nginx 再把请求转发给后端的应用服务器（比如运行 Python、Java、Node.js 的程序），拿到结果后再返回给用户。这样做的好处是：

- 隐藏了后端服务器的真实地址，更安全
    
- 可以负载均衡，把请求分发给多台后端服务器
    
- 后端服务重启时，Nginx 可以暂时接管，减少对用户的影响
    

**3. 负载均衡**  
当网站流量很大时，一台服务器扛不住。Nginx 可以把请求按照一定策略（轮询、加权、IP 哈希等）分发到多台服务器上，从而提升整体的处理能力。

**4. 反向代理缓存**  
Nginx 可以把后端返回的内容缓存起来。下次有相同请求时，直接返回缓存内容，不用再麻烦后端服务器，能大幅提升响应速度。

**5. SSL/TLS 终端**  
Nginx 可以处理 HTTPS 的加密和解密工作，让后端服务器专注于业务逻辑，不用操心证书和加密。

### 为什么 Nginx 这么快？

关键在于它的**事件驱动架构**。传统的服务器（如 Apache 的 prefork 模式）会为每个连接创建一个进程或线程，连接一多，内存和 CPU 切换开销就很大。而 Nginx 用少量工作进程配合异步非阻塞 I/O，一个进程就能同时处理成千上万个连接，所以在高并发场景下表现非常出色。

### 常见使用场景

- **静态网站托管**：直接放 HTML、图片、前端打包后的文件
    
- **API 网关**：统一入口，转发请求到不同的微服务
    
- **负载均衡器**：放在多台 Web 服务器前面分发流量
    
- **反向代理 + 缓存**：加速动态网站，减轻后端压力
