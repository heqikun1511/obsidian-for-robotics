[[Purepursuit]]




##  一、公式在说什么

$Pt=Pi+st−sisi+1−si(Pi+1−Pi)Pt​=Pi​+si+1​−si​st​−si​​(Pi+1​−Pi​)$

一句话：**已知路径上相邻两个点 PiPi​ 和 Pi+1Pi+1​，以及目标点在这段路径上的弧长 stst​，求目标点的坐标 PtPt​。**

---

## 二、每个符号的含义

| 符号        | 含义                                  |
| --------- | ----------------------------------- |
| PiPi​     | 第 ii 个离散路径点的坐标（已知）                  |
| Pi+1Pi+1​ | 第 i+1i+1 个离散路径点的坐标（已知）              |
| sisi​     | 第 ii 个路径点对应的累计弧长（已知）                |
| si+1si+1​ | 第 i+1i+1 个路径点对应的累计弧长（已知）            |
| stst​     | 目标点的累计弧长，满足 si≤st≤si+1si​≤st​≤si+1​ |
| PtPt​     | 要求的目标点坐标                            |
|           |                                     |


## 三、比例系数 $st−sisi+1−sisi+1​−si​st​−si​$​

这个分数表示：**目标点在 PiPi​ 到 Pi+1Pi+1​ 这段路上的"进度"**。

- 分子 st−sist​−si​：目标点从 PiPi​ 出发，已经走了多少弧长。
    
- 分母 si+1−sisi+1​−si​：整段 Pi→Pi+1Pi​→Pi+1​ 的总弧长。
    
- 比值范围：[0,1][0,1]。
