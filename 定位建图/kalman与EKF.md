[[协方差]]
## 0. 一句话理解 Kalman Filter

Kalman Filter（卡尔曼滤波，KF）不断重复两步：

1. 用运动模型预测“现在可能在哪里”；
    
2. 用传感器测量修正预测，并根据双方的不确定性决定更相信谁。
    

其本质是：在高斯噪声和线性模型条件下，对隐藏状态进行递归贝叶斯估计。

```
上一时刻后验估计
        ↓ 运动模型
当前时刻先验预测
        ↓ 新测量修正
当前时刻后验估计
        ↓
进入下一轮
```


# 1. 为什么需要滤波

## 1.1 真实状态通常不可直接获得

机器人真正的位置、速度和姿态称为**状态**。传感器只能间接观察状态，并且含有噪声。

例如：

- 编码器积分可以估计位移，但轮胎打滑会产生累计误差；
    
- IMU频率高，但零偏积分后会漂移；
    
- GNSS不累计漂移，但更新慢、会跳动或短时失锁；
    
- 激光雷达定位较准确，但依赖环境和匹配质量。
    

单一传感器往往无法同时满足高频、准确和长期稳定。滤波的目的，是将运动模型和多个测量的信息按照可信程度进行融合。

## 1.2 状态、估计值和测量值

需要严格区分：

- $(\mathbf{x}_k)$：第(k)时刻的真实状态，通常未知；
    
- ($\hat{\mathbf{x}}_k$)：对真实状态的估计；
    
- ($\mathbf{z}_k$)：传感器测量；
    
- ($\mathbf{u}_k$)：已知控制输入。
    

符号上方的“帽子”表示估计值。真实状态不会直接进入程序，因为它正是我们要估计的未知量。



## 1.3 估计不仅是一个数，还要带不确定性

假设机器人位置估计为10 m：

- ($10\pm0.01) m$表示非常确定；
    
- $(10\pm5) m$表示很不确定。
    

卡尔曼滤波用协方差矩阵(\mathbf{P})表示估计误差的不确定性：

[  
$\mathbf{P}_k=E[(\mathbf{x}_k-\hat{\mathbf{x}}_k)(\mathbf{x}_k-\hat{\mathbf{x}}_k)^T]$  
]

一维情况下，(P)就是误差方差；多维情况下：

- 对角元素：各状态自身的方差；
    
- 非对角元素：不同状态误差之间的相关性。



# 2. 必要的概率基础

## 2.1 高斯分布

一维高斯分布写作：

$[$  
$x\sim\mathcal N(\mu,\sigma^2)$  
$]$

其中$(\mu)$是均值，$(\sigma^2)$是方差。

多维高斯分布写作：

$[$  
$\mathbf{x}\sim\mathcal N(\boldsymbol\mu,\mathbf{P})$  
$]$

### 为什么只需要 μμ 和 PP 这两个参数？

高斯分布有一个极其优美的数学性质：**只要知道了均值和方差（协方差），整个分布的形状就完全确定了。**
- **μμ（均值向量，Mean Vector）**：决定了这个多维高斯分布**中心点在哪里**（也就是概率密度最高的位置）。
    
- **PP（协方差矩阵，Covariance Matrix）**：决定了这个分布的**形状、大小和方向**。
    
    - 对角线元素：代表各个维度自身的方差（数据波动多大）。
        
    - 非对角线元素：代表维度之间的相关性（比如“位置”和“速度”是不是正相关的）。
        
    - 如果 PP 是一个对角阵，说明各个维度相互独立；如果不是对角阵，说明维度之间存在耦合（分布形状是倾斜的椭圆）。
- 

其中$(\boldsymbol\mu)$是均值向量，$(\mathbf{P})$是协方差矩阵。

KF始终维护一个高斯分布：

- 均值($\hat{\mathbf{x}}$)：当前最可能的状态；
    
- 协方差($\mathbf{P}$)：对这个估计有多不确定。

## 2.2 独立噪声相加时方差相加

若(a)和(b)相互独立，则：

[  
$\operatorname{Var}(a+b)=\operatorname{Var}(a)+\operatorname{Var}(b)$  
]

这解释了预测时为什么要把过程噪声协方差($\mathbf{Q})$加到$(\mathbf{P})$上：每推进一步，模型误差会引入新的不确定性。

## 2.3 贝叶斯思想

$[$  
$p(\mathbf{x}\mid\mathbf{z})$  
$\propto$  
$p(\mathbf{z}\mid\mathbf{x})p(\mathbf{x})$  
$]$

- ($p(\mathbf{x}))$：看到新测量前的先验；
    
- $(p(\mathbf{z}\mid\mathbf{x})$)：如果状态是($\mathbf{x}$)，出现测量($\mathbf{z}$)的可能性；
    
- ($p(\mathbf{x}\mid\mathbf{z}))$：融合测量后的后验。
    

卡尔曼滤波就是在线性高斯条件下，以矩阵公式高效执行上述贝叶斯更新


# 3. 状态空间模型

## 3.1 状态转移方程

线性离散系统写为：

$[$  
$\mathbf{x}_k$  
$=\mathbf{F}_k\mathbf{x}_{k-1}$  
$+\mathbf{B}_k\mathbf{u}_k$  
$+\mathbf{w}_k$  
$]$

其中：

| 符号                 | 含义      |
| ------------------ | ------- |
| $(\mathbf{x}_{k-1})$ | 上一时刻状态  |
| $(\mathbf{F}_k)$     | 状态转移矩阵  |
| $(\mathbf{u}_k)$     | 控制输入    |
| $(\mathbf{B}_k)$     | 控制输入矩阵  |
| $(\mathbf{w}_k)$     | 过程噪声    |
| $(\mathbf{Q}_k)$     | 过程噪声协方差 |
通常假设：

[  
$\mathbf{w}_k\sim\mathcal N(\mathbf0,\mathbf{Q}_k)$  
]

## 3.2 测量方程

[  
$\mathbf{z}_k=\mathbf{H}_k\mathbf{x}_k+\mathbf{v}_k$  
]

其中：

| 符号             | 含义            |
| -------------- | ------------- |
| $(\mathbf{z}_k)$ | 传感器测量向量       |
| $(\mathbf{H}_k)$ | 将状态映射到测量空间的矩阵 |
| $(\mathbf{v}_k)$ | 测量噪声          |
| $(\mathbf{R}_k)$ | 测量噪声协方差       |

通常假设：

[  
$\mathbf{v}_k\sim\mathcal N(\mathbf0,\mathbf{R}_k)$  
]




### H不是传感器本身

$(\mathbf{H}$)回答的问题是：“如果状态估计为($\mathbf{x}$)，传感器理论上应该测到什么？”

例如状态为：

[  
$\mathbf{x}=\begin{bmatrix}p\v\end{bmatrix}$  
]

若传感器只测位置，则：

[  
$\mathbf{z}=\begin{bmatrix}1&0\end{bmatrix}\mathbf{x}+v$  
]

因此：

[  
$\mathbf{H}=\begin{bmatrix}1&0\end{bmatrix}$  
]

它从完整状态中“取出位置”。

# 4. 一维加权融合：先理解 Kalman Gain

假设：

- 预测位置为$(\hat{x}^-=10)$ m，预测方差$(P^-=4)$；
    
- 传感器测得(z=12) m，测量方差(R=1)。
    

一维卡尔曼增益：

[  
$K=\frac{P^-}{P^-+R}$  
$=\frac4{4+1}=0.8$  
]

更新状态：

[  
$\hat{x}^+=\hat{x}^-+K(z-\hat{x}^-)$  
]

[  
$\hat{x}^+=10+0.8(12-10)=11.6\text{ m}$  
]

更新方差：

[  
$P^+=(1-K)P^-=0.8$  
]

解释：预测方差比测量方差大，说明预测更不可靠，所以结果明显靠近测量值12 m。

### Kalman Gain 的直觉

- (P^-)大、(R)小：预测不确定、测量可靠，(K)大，更信测量；
    
- (P^-)小、(R)大：预测可靠、测量嘈杂，(K)小，更信预测。
    

不要简单把(K)理解成永远在0到1之间的“权重”。一维直接测量时如此，但多维矩阵(\mathbf{K})包含状态间相关性，其元素不一定都在0到1之间。



# 5. 线性 Kalman Filter 完整公式

记号：

- 上标(-)：融合当前测量之前的先验；
    
- 上标(+)：融合当前测量之后的后验。
    

## 5.1 预测步骤

### 状态预测

$[$  
$\boxed{\hat{\mathbf{x}}_k^-$  
$=\mathbf{F}_k\hat{\mathbf{x}}_{k-1}^+$  
$+\mathbf{B}_k\mathbf{u}_k}$  
$]$

用上一时刻最优估计和控制输入预测当前状态。

### 协方差预测

[  
$\boxed{\mathbf{P}_k^-$  
$=\mathbf{F}_k\mathbf{P}_{k-1}^+\mathbf{F}_k^T$  
$+\mathbf{Q}_k}$  
$]$

为什么两侧分别乘$(\mathbf{F})和(\mathbf{F}^T)$？因为若随机向量经过线性变换($\mathbf{y}=\mathbf{A}\mathbf{x})$，则：

[  
$\operatorname{Cov}(\mathbf{y})$  
$=\mathbf{A}\operatorname{Cov}(\mathbf{x})\mathbf{A}^T$  
]

再加(\mathbf{Q})，表示运动模型在这一步新引入的误差。
