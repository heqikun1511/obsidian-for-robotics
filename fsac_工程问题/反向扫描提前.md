[[转弯打滑问题]]

这个反向扫描是在保证：**车辆在进入每一个低速区之前，已经有足够的距离把速度降下来。**

假设从路径点 \(i-1\) 到 \(i\) 的距离为 \(\Delta s\)，最大可用制动减速度的绝对值为 \(a_{\text{brake}}>0\)。

若车辆在 \(i-1\) 的速度为 \(v_{i-1}\)，经过这段距离全力制动后，刚好在 \(i\) 降到 \(v_i\)，由匀减速运动学：

$\[ v_i^2=v_{i-1}^2-2a_{\text{brake}}\Delta s \]$

整理得：

$\[ v_{i-1}^2=v_i^2+2a_{\text{brake}}\Delta s \]$

因此，上一个路径点允许的最高速度是：

$\[ \boxed{ v_{i-1,\max}= \sqrt{v_i^2+2a_{\text{brake}}\Delta s} } \]$

若它原本的速度上限更高，也必须压低：

$\[ \boxed{ v[i-1] \leftarrow \min\left( v[i-1], \sqrt{v[i]^2+2a_{\text{brake}}\Delta s} \right) } \]$

例如，弯道入口限速 \(2\,\mathrm{m/s}\)，最大制动减速度为 \(2\,\mathrm{m/s^2}\)，距离弯道 \(3\,\mathrm m\)：

$\[ v_{\max}=\sqrt{2^2+2\times2\times3}=4\,\mathrm{m/s} \]$

也就是说，车辆在弯道前 3 米处的速度不能超过 \(4\,\mathrm{m/s}\)，否则即使立刻全力刹车，也不能及时降到 \(2\,\mathrm{m/s}\)。

反向扫描的原因在于：终点停车、障碍物、限速区或急弯的低速约束，会逐段向前传播。

```
较高初始速度 → 提前减速 → 低速入弯 → 继续行驶
```
