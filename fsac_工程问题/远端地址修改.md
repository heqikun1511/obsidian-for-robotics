主仓库的远端地址改为：

```
cd /home/amoy/fsac_driveless/driverless_workspace/workspace/autonomous_system/stacks/rt_control

git remote set-url origin \
  https://gitlab.amoyfs.top:20398/driverless/stacks/rt_control.git

git remote -v
```

输出应显示新的 `https://gitlab.amoyfs.top:20398/...` 地址。

同时，`.repos` 里的依赖地址也应从旧 SSH 地址改为新 HTTPS 地址，例如：

```
url: https://gitlab.amoyfs.top:20398/driverless/ros-packages/fsac_control_node.git
```

已克隆到本地的依赖仓库不会自动更新 remote；可逐个执行：

```
git -C src/racecar_description remote set-url origin \
  https://gitlab.amoyfs.top:20398/driverless/ros-packages/racecar_description.git
```

其他 `src/*` 仓库同理。之后首次 `git push` 可能需要输入 GitLab 用户名和 Personal Access Token。
