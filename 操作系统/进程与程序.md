# 虚拟化：

## 从汉诺塔的非递归版本说起

- 选择一个进程；
- 让这个进程执行一步；
- 再选择一个进程；
- 不断重复上述过程。

## CrazyOS 的核心循环
## 与真实操作系统的对应关系

| 抽象代码            | 操作系统概念       |
| --------------- | ------------ |
| `p`             | 一个进程及其执行状态   |
| `pick(p)`       | 进程调度         |
| `single_step()` | 让进程继续执行      |
| 保存和恢复 `p` 的状态   | 上下文切换        |
| `while (1)`     | 操作系统持续管理程序执行 |
真实操作系统需要完成以下工作：

1. 维护每个进程的执行状态；
2. 从可运行的进程中选择下一个进程；
3. 将 CPU 的控制权交给该进程；
4. 在适当的时机重新获得 CPU 控制权；
5. 保存当前进程的状态；
6. 恢复并切换到另一个进程。

## 虚拟化的意义

操作系统通过以下机制：

- 分时调度；
- 保存进程状态；
- 恢复进程状态；
- 在多个进程之间切换；

使每个程序都产生一种“自己独占 CPU”的错觉。

这就是 **CPU 虚拟化**的基本思想。
