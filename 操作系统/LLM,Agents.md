### 从预训练到有用的 AI

**预训练（Pre-training）：** 在海量文本上学习“预测下一个 token”。模型在这个过程内化了语言结构、世界知识和推理模式。

**对齐（Alignment / RLHF）：** 让模型从“会说话”变成“会帮忙”。没有对齐的 LLM 像一个读了所有书但不懂社交的人。

**涌现（Emergence）：** 当模型足够大时，出现了训练目标中没有显式要求的能力（如数学推理、代码生成）。这就是“大”的力量。






### Agent 能力的进化与核心架构

#### 一、 Agent 能力的进化路径
（来源：jyy 梳理）

*   **1. “感知” (XLS)**
    *   一回“感官”都可以对齐到语言系统上。
    *   *（解释：让 AI 能看懂图、听懂声音，转化为语言理解。）*

*   **2. “思维链” (Chain-of-Thought)**
    *   GPT-4 时代的宝藏 prompt：“think step by step”。
    *   相当于这是在帮我们想出一个 plan。
    *   *（局限：虽然 AI 自己不能确保自己想的是对的，但这是规划的基础。）*

*   **3. “计算器” (React & Toolformer)**
    *   知道 123 + 456 算不对，那就“结果是 | python3 -c "123 + 456" |”。
    *   这就是 AI 的外挂。
    *   *（解释：AI 学会调用外部工具来弥补自身短板。）*

---

#### 二、 Agent 的核心：感知 + 推理 + 工具
> **核心定义**：Agent 不是一个更聪明的 chatbot。它是 **LLM + 工具调用 + 规划能力**的组合。

**关键进化：**

1.  **感知**：多模态输入（文本、图像、音频）。
2.  **推理**：Chain-of-Thought 让 LLM “先想再做”。
3.  **工具**：ReAct/Toolformer 让 LLM 调用外部工具（计算器、搜索引擎、代码执行器）。
4.  **行动**：MCP 等协议让 Agent 能操作真实系统。



### MCP 对操作系统的意义

**MCP (Model Context Protocol)** 是 Agent 与外部工具交互的标准协议。类比操作系统的 `syscall`——

*   `syscall` 是程序与 OS 的接口
*   `MCP` 是 Agent 与工具生态的接口

**MCP 之于 Agent，就像 POSIX 之于 UNIX**——它定义了一个标准化的工具调用接口，使得任何 Agent 都可以使用任何工具。



### 3.2 Scaling Law: 算力 → 能力

#### 为什么 OpenAI 敢训练更大的模型？

*   **实验科学**：
    *   参考论文："Kaplan's Scaling Law Paper" [1] & "Chinchilla Paper" [2]。
    *   我们甚至不知道 optimal（最优解）在哪里，人类就造出智能机器了。
    *   这和“生物进化”很像：人类也是 highly suboptimal（高度次优）的。

> **核心洞察**：
> Scaling Law 是一条经验规律，它揭示了模型性能（Loss）与模型大小（参数量）、数据量、算力之间的幂律关系。这意味着我们可以通过持续增加算力和数据，来“暴力”换取模型能力的提升。

#### 关键参考文献：
1.  [https://arxiv.org/abs/2203.15556](https://arxiv.org/abs/2203.15556) (Chinchilla)
2.  [https://arxiv.org/pdf/2001.08361](https://arxiv.org/pdf/2001.08361) (Kaplan)


### Scaling Law 的核心发现

**OpenAI 的 Scaling Law  发现：**
模型的 loss 与三个因素呈**幂律关系 (power law)**：

$$L(N, D, C) \propto N^{-\alpha_N} + D^{-\alpha_D} + C^{-\alpha_C}$$

*   $N$：模型参数量
*   $D$：训练数据量
*   $C$：计算量 (FLOPs)
*   $\alpha$：缩放指数（经验常数）

**含义：** 只要持续增加算力、数据和参数，模型能力就会持续提升——而且是**可预测的提升**。


**2. “可预测的提升”才是最重要的
*   如果只是“变大就变强”，那只是盲目的烧钱。
*   但 Scaling Law 的精髓在于，它是一条 **平滑的曲线**。在训练之前，OpenAI 就可以根据这个公式，**精准预测** 出投入多少算力和数据后，模型最终的 Loss 会是多少。
*   这就好比造火箭前，就已经算好了推力与重量的关系，让你敢放心地造更大的火箭。
#### 3. 对 AI 行业的深远影响
*   这个发现直接导致了 **“大力出奇迹”** 成为过去几年 AI 发展的主旋律。
*   它给了科技巨头们一个明确的信号：**只要有钱买卡（\(C\)）、有数据（\(D\)）、把模型做大（\(N\)），能力就一定会按比例增长。**
*   这直接催生了 GPT-3、GPT-4 等超大参数模型的诞生。**
#### 4**训练时 Scaling：**
更大的模型 + 更多数据 = 更好的基础能力。代表：GPT-3 → GPT-4。
**推理时 Scaling（2024+）：**
同一个模型，用更多的推理计算（如 Chain-of-Thought、Tree Search、多次采样）= 更好的回答。代表：o1、deepseek-r1。
**类比：**
训练时 Scaling 像“上更多年的学”；推理时 Scaling 像“考试时想得更久”。两者正交，可以叠加。
