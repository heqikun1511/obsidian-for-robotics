
将 Gemini 305 直接接到树莓派或电脑的 USB 3.0 接口，尽量不要先使用无外部供电的 USB Hub。

```

dmesg -w
```

应能看到 Orbbec / Gemini 类设备枚举信息。若频繁断连或无法识别，优先更换 USB 3.0 数据线、接口，或使用带独立供电的 Hub。

2. 在当前电脑安装并验证驱动

你的当前 x86_64 Jazzy 系统的软件源已有驱动包，可直接安装：

```
sudo apt update
sudo apt install ros-jazzy-orbbec-camera ros-jazzy-orbbec-description
```

安装 USB 权限规则，否则普通用户可能无法打开相机：

```
sudo cp /opt/ros/jazzy/share/orbbec_camera/udev/99-obsensor-libusb.rules \
  /etc/udev/rules.d/

sudo udevadm control --reload-rules
sudo udevadm trigger
```

重新插拔相机后，检查设备：

```
source /opt/ros/jazzy/setup.bash
ros2 run orbbec_camera list_devices_node
```

启动 Gemini 305：

```
ros2 launch orbbec_camera gemini_301_series.launch.py
```

Gemini 305 官方建议固件版本为 `1.0.70`；首次可先不升级，确认能稳定出图后再根据官网文档判断是否需要升级。[官方设备与启动文件表](https://github.com/orbbec/OrbbecSDK_ROS2/blob/v2-main/README.MD)
