## Calculus of Variations（变分法）

第三讲是后续 PMP、间接法最重要的数学起点：把“对有限维变量求极值”推广为“对一整条函数/轨迹求极值”。本讲尚未正式进入 PMP；它先推导出 Euler–Lagrange 方程。[stanfordasl.github.io](https://stanfordasl.github.io//aa203/sp2526/pdfs/lecture/lecture_3.pdf?utm_source=chatgpt.com)

### 1. 从优化一个数，到优化一条轨迹

普通优化：

$\[ \min_z f(z) \]$

无约束局部极值的必要条件：

$\[ \nabla f(z^\ast)=0 \]$

变分法处理的是泛函（functional）：

$\[ \min_{x(\cdot)} J[x] \]$

其中 \(J\) 的输入不是一个向量，而是一整个函数 \(x(t)\)。典型形式：

$\[ J[x]=\int_{t_0}^{t_f} g(x(t),\dot{x}(t),t)\,dt \]$

例如，寻找两点之间长度最短的曲线，本质就是在所有候选曲线中最小化一个泛函；结果是直线。[stanfordasl.github.io](https://stanfordasl.github.io//aa203/sp2526/pdfs/lecture/lecture_3.pdf?utm_source=chatgpt.com)

### 2. “扰动变量”变为“扰动函数”

给候选轨迹 \(x(t)\) 加一个小扰动：

$\[ x(t)\rightarrow x(t)+\delta x(t) \]$

对应泛函的增量：

$\[ \Delta J = J[x+\delta x]-J[x] \]$

其一阶部分称为一阶变分：

$\[ \delta J = \int_{t_0}^{t_f} \left( \frac{\partial g}{\partial x}\delta x + \frac{\partial g}{\partial \dot{x}}\delta\dot{x} \right)dt \]$

它就是普通优化中 $\(\nabla f^\top\delta z\)$ 的无限维对应物。

若 \(x^\ast(t)\) 是局部极值轨迹，则对所有允许扰动都必须有：

$\[ \delta J[x^\ast,\delta x]=0 \]$

这只是极值的必要条件，不保证一定是最小值；后续还可能需要二阶条件、凸性或结构分析。

### 3. 分部积分：核心推导动作

因为 \(\delta \dot{x}\) 出现在积分中，无法直接由“扰动任意”得出结论。对该项分部积分：

$\[ \int_{t_0}^{t_f} \frac{\partial g}{\partial \dot{x}} \delta \dot{x}\,dt = \left[ \frac{\partial g}{\partial \dot{x}}\delta x \right]_{t_0}^{t_f} - \int_{t_0}^{t_f} \frac{d}{dt} \left( \frac{\partial g}{\partial \dot{x}} \right) \delta x\,dt \]$

第三讲讨论的是固定初末时刻、固定两端状态：

$\[ x(t_0)=x_0,\qquad x(t_f)=x_f \]$

因此允许的轨迹扰动需满足：

$\[ \delta x(t_0)=\delta x(t_f)=0 \]$

边界项消失，得到：

$\[ \delta J = \int_{t_0}^{t_f} \left[ \frac{\partial g}{\partial x} - \frac{d}{dt} \left( \frac{\partial g}{\partial \dot{x}} \right) \right]\delta x\,dt \]$

### 4. Fundamental Lemma 与 Euler–Lagrange 方程

变分法基本引理说：若连续函数 \(h(t)\) 满足

$\[ \int_{t_0}^{t_f}h(t)\delta x(t)\,dt=0 \]$

且对所有允许的连续扰动 \(\delta x(t)\) 都成立，则必有：

$\[ h(t)=0,\quad \forall t\in[t_0,t_f] \]$

因此，极值轨迹 \(x^\ast(t)\) 必须满足 Euler–Lagrange 方程：

$\[ \boxed{ \frac{\partial g}{\partial x} - \frac{d}{dt} \left( \frac{\partial g}{\partial \dot{x}} \right) =0 } \]$

向量状态时：

$\[ \boxed{ \nabla_x g - \frac{d}{dt} \left( \nabla_{\dot{x}}g \right) =0 } \]$

这通常是一个二阶、非线性、时变常微分方程；由于条件分布在 \(t_0\) 和 \(t_f\)，它是一个两点边值问题（BVP），而不是普通的初值问题（IVP）。[stanfordasl.github.io](https://stanfordasl.github.io//aa203/sp2526/pdfs/lecture/lecture_3.pdf?utm_source=chatgpt.com)

### 5. 它和最优控制的关系

第三讲的 \(x\) 与 \(\dot{x}\) 都被看作自由曲线的一部分；而真实最优控制问题有动力学约束：

\[ \dot{x}=f(x,u,t) \]

并要最小化：

\[ J= \phi(x(t_f),t_f) + \int_{t_0}^{t_f}l(x,u,t)\,dt \]

下一讲会用拉格朗日乘子函数（costate）\(\lambda(t)\) 将动力学约束并入目标：

\[ \mathcal{H}(x,u,\lambda,t) = l(x,u,t)+\lambda^\top f(x,u,t) \]

最终就得到 PMP 的状态方程、协态方程、驻值/最小化条件和边界条件。换句话说：

\[ \text{Euler–Lagrange} \longrightarrow \text{引入动态约束} \longrightarrow \text{PMP} \]

这也是你之后理解单射击法、iLQR、MPCC，乃至 LMPC 中“伴随变量/梯度反传”概念的根基。
