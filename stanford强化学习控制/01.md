## 这门课在学什么

AA203 的目标是把最优控制与学习型控制放到同一个框架中理解：

```
已知模型
  ├─ 开环最优控制：间接法、直接法、轨迹优化
  ├─ 闭环最优控制：动态规划、HJB/HJI、MPC
  └─ 模型不准确：自适应最优控制

模型未知或不完整
  ├─ 模仿学习
  ├─ 基于模型的强化学习
  └─ 无模型强化学习
```

对你的机器人/赛车场景而言：

- 轨迹规划：给出未来参考路径；
- Pure Pursuit、PID 等：让车跟踪路径；
- MPC：在未来预测窗口内，边预测边优化控制量；
- RL：模型未知、模型不够准或希望从数据中改善策略时使用。

课程强调“广度优先”：会覆盖优化、轨迹优化、DP、MPC、系统辨识、模仿学习、强化学习，但具体细节需要自己额外推导和练习。

## 2. 从反馈控制开始

最基本的反馈控制结构是：

```
参考值 r ─→ [控制器] ─→ u ─→ [系统] ─→ y
                   ↑                 │
                   └──── 测量值 ──────┘
```

其中：

- \(r\)：参考值，如期望速度、期望轨迹；
- \(u\)：控制输入，如油门、转角、轮速；
- \(y\)：系统输出，如实际速度、位置、姿态；
- 控制器根据误差 \(r-y\) 持续修正控制量。

以无人赛车为例：

```
参考轨迹 r：赛道中心线 + 期望速度
控制输入 u：前轮转角 δ、纵向加速度 a
系统：车辆动力学
输出 y：位置、航向角、速度
```

现实系统还会有扰动与测量噪声：

\[ $x_{k+1}=f(x_k,u_k)+w_k,\qquad y_k=h(x_k)+v_k$ \]

- \(w_k\)：外部扰动、轮胎模型误差、坡度、侧滑；
- \(v_k\)：定位、IMU、雷达等测量噪声。
第一讲提出优秀控制器的四项要求：

1. **稳定性**：状态不发散，不失控；
2. **跟踪性**：尽量贴近期望轨迹；
3. **抗扰性**：扰动来临后不要明显偏离；
4. **鲁棒性**：模型不准时依然能工作。[stanfordasl.github.io](https://stanfordasl.github.io//aa203/sp2526/pdfs/lecture/lecture_1.pdf?utm_source=chatgpt.com)

## 3. 为什么需要“最优控制”

传统 PID 能稳定、能跟踪，但它不天然回答这些问题：

- 跟踪误差和控制动作哪个更重要？
- 转向幅度不能超过多少？
- 轮胎侧偏、速度、障碍物等约束如何统一处理？
- 如何提前考虑未来几秒的弯道？

最优控制就是把这些要求写成一个明确的数学问题：

```
在满足动力学与约束的前提下，
寻找一段最好的控制输入，
使总代价最小。
```

“最好的”由你定义。例如赛车中可以希望：

$\[ J= \sum_{k=0}^{N-1} \left( q_e e_k^2+ q_\psi e_{\psi,k}^2+ q_v(v_k-v_{\mathrm{ref},k})^2+ r_\delta \delta_k^2+ r_a a_k^2 \right) \]$

它表达的是：

- 不要离路径太远；
- 航向不要偏太多；
- 速度尽量跟踪目标；
- 不要猛打方向；
- 不要猛加速或急减速。

权重 \(q_e,q_\psi,q_v,r_\delta,r_a\) 就是设计者对“好驾驶”的量化偏好。
## 4. 最优控制问题的标准形式

### 连续时间模型

系统状态与控制输入满足：

$\[ \dot{x}(t)=f(x(t),u(t),t) \]$

其中：

- $\(x(t)\in\mathbb{R}^n\)：状态；$
- $\(u(t)\in\mathbb{R}^m\)：控制输入；$
- $\(f(\cdot)\)：系统动力学。$

例如二维点质量模型：

$\[ x= \begin{bmatrix} p_x\\p_y\\v_x\\v_y \end{bmatrix}, \qquad u= \begin{bmatrix} a_x\\a_y \end{bmatrix} \]\[ \dot p_x=v_x,\quad \dot p_y=v_y,\quad \dot v_x=a_x,\quad \dot v_y=a_y \]$

这就是双积分器模型：控制加速度，产生速度变化，速度积分后产生位置变化。
### 约束

真实系统不可能任意控制，因此必须加入约束：

$\[ u(t)\in \mathcal U \]$

例如：

$\[ |\delta|\le\delta_{\max},\qquad |a|\le a_{\max},\qquad 0\le v\le v_{\max} \]$

还可能有：

- 初始条件：\(x(t_0)=x_0\)；
- 终端条件：\(x(t_f)=x_f\)；
- 状态约束：避障、赛道边界、叉车门架限位；
- 控制变化率约束：\(|\dot\delta|\)、\(|\dot a|\) 有限。

满足所有约束的控制叫 **admissible control（可行控制）**；对应产生的状态路径叫 **admissible trajectory（可行轨迹）**。

### 代价函数

最常见形式：

$\[ J= h(x(t_f),t_f) + \int_{t_0}^{t_f} g(x(t),u(t),t)\,dt \]$

- \(g\)：运行代价（running/stage cost），表示每个时刻的损失；
- \(h\)：终端代价（terminal cost），表示最终状态是否达到目标。

最优控制问题可以写成：

$\[ \begin{aligned} \min_{u(\cdot)}\quad& h(x(t_f),t_f)+ \int_{t_0}^{t_f}g(x(t),u(t),t)\,dt\\ \text{s.t.}\quad& \dot x=f(x,u,t)\\ &x(t_0)=x_0\\ &x(t)\in\mathcal X,\quad u(t)\in\mathcal U \end{aligned} \]$

第一讲最重要的理解是：**最优控制不是某一个算法，而是一类“动力学约束下的优化问题**

## 开环控制与闭环策略

### 开环最优控制

$\[ u^\ast(t)=e(x(t_0),t) \]$

含义：根据初始状态一次性算出整段控制序列。

优点：计算与理论分析相对直接。  
缺点：中途被扰动后不会自动纠正。

例如：在仿真里根据初始位置算出一整条赛车轨迹，再直接执行。

### 闭环最优控制

$\[ u^\ast(t)=\pi(x(t),t) \]$

\(\pi\) 称为策略（policy）或控制律（control law）。

含义：每个时刻读取当前状态，再决定当前控制输入。

例如 LQR：

\[ u=Fx \]

MPC、动态规划、许多 RL 方法，本质上都在寻找或近似这个状态到动作的映射：

$\[ \pi:\ x\mapsto u \]$
## 离散时间形式：后续 MPC、DP、RL 的共同语言

机器人软件通常按周期运行，例如 50 Hz 或 100 Hz，因此常用离散形式：

\[ $x_{k+1}=f_k(x_k,u_k)$ \]

总代价：

\[ $J(x_0;u_0,\dots,u_{N-1}) = h_N(x_N)+ \sum_{k=0}^{N-1}g_k(x_k,u_k)$ \]

目标：

\[ $J^\ast(x_0)= \min_{u_0,\dots,u_{N-1}}J(x_0;u_0,\dots,u_{N-1})$ \]

这就是未来 \(N\) 步的决策问题。

- **MPC**：每次只执行最优序列的第一步，然后重新测量并再优化；
- **动态规划**：从终点往前递推价值函数；
- **RL**：用数据学习价值函数或策略；
- **轨迹优化**：直接把所有 \(x_k,u_k\) 当作变量一起优化。

后面所有内容都可看成是在解决或近似这个离散优化问题。

## 非线性优化入门

第一讲最后进入最优控制的基础工具：非线性优化。

最简单的无约束问题：

$\[ \min_{x\in\mathbb{R}^n}f(x) \]$

### 局部最小与全局最小

局部最小：只在 \(x^\ast\) 附近比周围点小。

\[ $\exists\epsilon>0,\quad f(x^\ast)\le f(x), \quad\forall x:\|x-x^\ast\|<\epsilon$ \]

全局最小：在整个可行域内都最小。

\[ $f(x^\ast)\le f(x),\quad\forall x$ \]

非凸问题可能有多个局部极小值，因此“优化器收敛”不等于“找到了全局最优”。

### 一阶必要条件

若 \(x^\ast\) 是可微无约束问题的局部极小点，则：

\[ $\nabla f(x^\ast)=0$ \]

即驻点。它只是候选点，不一定是最小值。

### 二阶必要条件

若 \(x^\ast\) 是局部极小点且 \(f\) 二阶可微，则：

\[ $\nabla^2f(x^\ast)\succeq0$ \]

Hessian 必须半正定。

### 二阶充分条件

若：

\[ $\nabla f(x^\ast)=0, \qquad \nabla^2 f(x^\ast)\succ0$ \]

则 \(x^\ast\) 是严格局部极小点。

直观理解：

- 梯度为 0：当前位置一阶方向上不再下降；
- Hessian 正定：附近像一个碗，任意小偏移都会使代价增加。

### 凸优化为何重要

如果可行域是凸集，\(f\) 也是凸函数：

- 局部最小就是全局最小；
- 若严格凸，全局最小至多一个；
- 对可微凸函数，\(\nabla f(x^\ast)=0\) 足以证明全局最优。

这就是为什么后续课程会反复区分：

```
凸问题：求解可靠、全局最优有保证
非凸问题：更贴近真实机器人，但可能卡在局部极小
```
