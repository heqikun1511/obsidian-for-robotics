



这是一个 **ESP32（FreeRTOS）上的旋转编码器任务**，负责读取**旋转编码器**的旋转方向，以及**按键（按下）** 事件，并通过队列发送给其他任务处理。代码用到了**四相正交解码**和**按键消抖**两种经典技术。

cpp

static void rotary_task(void *arg)
{

- `static`：文件内可见

- `while (true)`：任务主循环，永不退出


## 旋转编码器基础

### 什么是旋转编码器？

旋转编码器（Rotary Encoder）是一种把**旋转角度/方向**转成电信号的器件。最常见的**增量式编码器**有两路输出：

- **A 相**：方波
    
- **B 相**：方波，与 A 相**相位差 90°**
    

text

顺时针旋转：
A: ─┐  ┌──┐  ┌──┐  ┌──
    └──┘  └──┘  └──┘
B: ──┐  ┌──┐  ┌──┐  ┌─
     └──┘  └──┘  └──┘
   A 领先 B 90°
逆时针旋转：
A: ──┐  ┌──┐  ┌──┐  ┌─
     └──┘  └──┘  └──┘
B: ─┐  ┌──┐  ┌──┐  ┌──
    └──┘  └──┘  └──┘
   B 领先 A 90°

**关键**：A、B 的**相位关系**决定旋转方向。


### 四相正交（Quadrature）

A 和 B 各有两个状态（0/1），组合成 **4 种状态**：

|A|B|状态|
|---|---|---|
|0|0|0|
|0|1|1|
|1|1|2|
|1|0|3|

旋转时，状态按固定顺序循环：

text

顺时针：0 → 1 → 3 → 2 → 0 → ...
逆时针：0 → 2 → 3 → 1 → 0 → ...



## 初始化部分

### 1. 读取初始状态

cpp

uint8_t previous_state =
    ((gpio_get_level(s_config.a_gpio) ? 1 : 0) << 1) |
    (gpio_get_level(s_config.b_gpio) ? 1 : 0);

- 读 A、B 两个 GPIO 的电平
    
- 组合成 2 位状态：`(A << 1) | B`
    
- 值域：`0b00` ~ `0b11`（0~3）
    

**示例**：A=1, B=0 → `(1 << 1) | 0 = 2`

### 状态变量

cpp

int8_t step_accumulator = 0;   // 步数累加器
uint8_t last_switch = 1;       // 上次按键原始状态
uint8_t stable_switch = 1;     // 消抖后的稳定状态
uint8_t switch_count = 0;      // 连续相同状态计数

| 变量                 | 作用               |
| ------------------ | ---------------- |
| `step_accumulator` | 累加旋转步数，达到 ±4 算一格 |
| `last_switch`      | 记录上一次读到的原始电平     |
| `stable_switch`    | 消抖后的稳定状态（1 = 松开） |
| `switch_count`     | 连续读到相同电平的次数      |
## 一格 = 4 步

cpp

/* A detent normally produces four valid state transitions. */
if (step_accumulator >= 4) {
    rotary_event_t event = ROTARY_EVENT_RIGHT;
    (void)xQueueSend(s_event_queue, &event, 0);
    step_accumulator = 0;
} else if (step_accumulator <= -4) {
    rotary_event_t event = ROTARY_EVENT_LEFT;
    (void)xQueueSend(s_event_queue, &event, 0);
    step_accumulator = 0;
}

**为什么是 4？**

机械旋转编码器每转一格（detent），A、B 会经历**完整的一个周期**，共 4 个状态转换：

text

一格（detent）的状态序列：
0 → 1 → 3 → 2 → 0   （4 步）
或
0 → 2 → 3 → 1 → 0   （4 步）

所以**累加器达到 ±4 = 转过一格**，发送一次事件，然后清


## 按键消抖

cpp

if (s_config.switch_gpio != GPIO_NUM_NC) {
    uint8_t raw_switch = gpio_get_level(s_config.switch_gpio) ? 1 : 0;
    if (raw_switch == last_switch) {
        if (switch_count < ROTARY_PRESS_FILTER_COUNT) {
            ++switch_count;
        }
    } else {
        switch_count = 0;
        last_switch = raw_switch;
    }
    if (switch_count >= ROTARY_PRESS_FILTER_COUNT &&
        stable_switch != raw_switch) {
        stable_switch = raw_switch;
        if (stable_switch == 0) {
            rotary_event_t event = ROTARY_EVENT_PRESS;
            (void)xQueueSend(s_event_queue, &event, 0);
        }
    }
}


### 消抖算法

**核心**：连续 N 次读到相同电平，才认为稳定。

|变量|作用|
|---|---|
|`last_switch`|上一次读到的原始电平|
|`stable_switch`|已确认的稳定状态|
|`switch_count`|连续相同次数|
|`ROTARY_PRESS_FILTER_COUNT`|需要的连续次数（如 5）|

**逻辑**：

1. 读当前电平 `raw_switch`
    
2. 如果和 `last_switch` 相同 → `switch_count++`（有上限）
    
3. 如果不同 → 重置 `switch_count`，更新 `last_switch`
    
4. 如果 `switch_count >= FILTER_COUNT` 且 `stable_switch != raw_switch`：
    
    - 更新 `stable_switch`
**关键点**：

- **只在按下时发事件**（`stable_switch == 0`），松开不发
    
- **只在状态变化时发**（`stable_switch != raw_switch`），不会重复发
    
- **`GPIO_NUM_NC`**：如果没接按键，跳过（可选功能）
    

**`active-low`**：按键按下时 GPIO = 0（接地），松开时 = 1（上拉）
