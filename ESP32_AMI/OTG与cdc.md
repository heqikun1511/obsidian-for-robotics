### 1. USB OTG

**OTG** 是 **On-The-Go** 的缩写。传统 USB 是主从结构：电脑（Host）控制外设（Device）。而 OTG 允许一个设备**既当主机，又当外设**。

比如手机通过 OTG 线连接 U 盘时，手机就是 Host；但手机通过 USB 线连电脑时，手机又变成了 Device。这种角色切换能力就是 OTG。

### 2. CDC

**CDC** 是 **Communications Device Class** 的缩写，是 USB 标准中定义的一类**通信设备**。USB 官方定义了很多设备类，比如：

- HID：键盘、鼠标
    
- MSC：U 盘、移动硬盘
    
- CDC：调制解调器、串口、网卡等通信设备
    

CDC 下面又细分了多个子类，最常见的是：

- **CDC-ACM**：抽象控制模型，用来模拟**虚拟串口**（Virtual COM Port）。设备插上电脑后，电脑会识别出一个串口，比如 `COM3` 或 `/dev/ttyACM0`。
    
- **CDC-ECM / CDC-NCM**：用来模拟**以太网网卡**，设备插上后电脑会多出一个网络接口。
    
- **CDC-MBIM**：移动宽带接口，常用于 4G/5G 模块。


### 3. 合起来：USB OTG CDC 设备

指的是一个支持 OTG 的 USB 设备，它按照 CDC 类规范来工作。实际中通常有两种理解：

**第一种：设备本身是 CDC 设备，通过 OTG 接口连接**  
比如一块开发板（STM32、ESP32 等）通过 USB OTG 接口连到电脑，固件里把它配置成 CDC-ACM 虚拟串口。电脑上就多出一个串口，可以像用普通串口一样收发数据。这是嵌入式开发中非常常见的调试和数据传输方式。

**第二种：设备作为 OTG 主机，去识别外部的 CDC 设备**  
比如手机通过 OTG 线连接一个 USB 转串口模块，手机作为 Host，去识别这个 CDC 设备并与之通信。

### 典型应用场景

- **嵌入式调试**：开发板通过 USB 虚拟串口输出日志、接收命令，不用额外的 USB 转串口芯片
    
- **USB 转串口模块**：常见的 CH340、CP2102 等，本质上就是 CDC 设备
    
- **4G/5G 模块**：通过 CDC-MBIM 或 CDC-ECM 提供网络连接
    
- **手机连接外设**：手机通过 OTG 连接串口设备、网卡等
    
- **设备间通信**：两块开发板通过 USB OTG 互相连接，一方作 Host，一方作 CDC Device
    

### 和普通 USB 设备的区别

普通 U 盘属于 **MSC** 类，插上后电脑把它当存储设备；而 CDC 设备插上后，电脑把它当**通信设备**，可能是一个串口，也可能是一块网卡。区别就在于 USB 描述符里声明的**设备类代码**不同。
