[[cpp语法]]
### `SocketCan(const SocketCan &) = delete;`

**禁止拷贝构造**。意思是不能这样写：

cpp

SocketCan a;
SocketCan b(a);        // 编译错误
SocketCan c = a;       // 编译错误

**为什么要禁止拷贝？**

SocketCan 内部管理的是一个 **socket 文件描述符（fd）**。文件描述符是操作系统资源，语义上**不能被随意复制**：

- 如果允许拷贝，两个对象会持有同一个 fd
    
- 其中一个析构时 `close(fd)`，另一个对象的 fd 就失效了
    
- 再次使用会导致「操作已关闭的 fd」，行为未定义
    

这是典型的 **RAII 资源管理类**：资源（fd）的生命周期绑定到对象生命周期，所以**拷贝必须禁止**。

### `SocketCan & operator=(const SocketCan &) = delete;`

**禁止拷贝赋值**。意思是不能这样写：

cpp

SocketCan a, b;
a = b;   // 编译错误

原因同上：如果允许赋值，`a` 原来持有的 fd 怎么处理？直接覆盖会泄漏，先关闭再复制又涉及所有权问题。禁止赋值是最简单、最安全的选择。
